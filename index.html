GitHub auto-save

Save your tracker data as a JSON file in a private GitHub repository.

Not connected

Use a private data repository and a fine-grained Personal Access Token restricted to that repository with Contents: Read and write. The token is kept in this browser tab's session storage, not committed to GitHub. Anyone who can access the token can edit the data.

Enter your private data repository details to enable auto-save.

After connection, changes are saved locally immediately and synced to GitHub automatically after a short delay. GitHub creates a commit for each sync. Do not use a public repository for employee records.

Important limitation

This is a static GitHub Pages application.

Without GitHub sync, data is stored only in this browser. With GitHub sync, the JSON data file is saved in the configured private repository. The Pages website may be public even if its source repository is private, depending on your GitHub plan and settings; keep employee data in a separate private repository. Export backups regularly.
